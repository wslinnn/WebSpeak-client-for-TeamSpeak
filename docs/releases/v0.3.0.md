# WebSpeak 0.3.0

本版本以 0.2.6 为基线，是本仓库发布的第一个正式版本。其间累计 746 次提交，主要工作集中在语音链路质量、屏幕共享跨网可达性、安全基线和工程结构。

## 语音链路

- **WebRTC 混音总线：** 增益管线改走共享混音总线，输出设备选择与超过 100% 的增益不再互斥；自动播放被浏览器拦截时结果单独上报，不再被误判为静音。
- **编码器对齐官方实现：** 两个网关 Opus 编码器统一钉参（24 kbps、`SIGNAL=VOICE`、`VOIP` 应用、带内 FEC、期望丢包 10%），上行明确声明单声道、下行保留立体声。
- **静音与时间线：** 静音跨度改为计数实现，任意长度的停顿不再制造假丢包洞；下行 RTP 时间线抽为独立模块，槽位复用保持连续。
- **出站积压：** 按说话者定容并按真实 Opus 包尺寸换算，上行预算只在路由可用的帧上计费。
- **降噪与回声：** 上行降噪换装 GTCRN（WASM），与浏览器原生降噪解耦；回声消除默认开启；麦克风增益上限提升至 200%。
- **说话检测：** 改用 `getSynchronizationSources`，不再为每个槽位轮询 `getStats`；说话徽标以 monotonic epoch 判龄，墙钟跳变不再误判。

## 屏幕共享

- **内置 STUN：** 网关自带 STUN 服务（默认 UDP `3478`，`WEBSPEAK_STUN_PORT` 可改端口、设为 `0` 关闭），屏幕共享无需依赖外部 STUN 即可发现公网候选。
- **跨网诊断：** 协商失败时透出实际尝试的发现服务、已发送候选计数与首帧证明，观看端和共享端都可自证分界；慢 ICE 死线不再被 `ontrack` 提前解除。
- **媒体链路：** 屏幕共享音频套用伴奏式音乐链路，P2P 全程不经 TeamSpeak 上行预算；共享设置面板对齐分辨率与帧率档位。
- **管理配置：** 管理员可配置公网媒体地址、IPv6 候选与语音 STUN，适配反向代理或 TCP 隧道后的部署。

## 安全

- **首次启动：** 不再有默认管理员口令，改为生成一次性设置令牌只打印到日志，登录后强制改密。
- **传输与响应头：** CSP、HSTS、`connect-src 'self'` 等安全响应头统一由全局中间件设置，并由测试做负向断言防回流。
- **限流：** WebSocket 控制消息令牌桶（60 突发 / 20 每秒），合并回执；TeamSpeak 服务器密码错误按目标计数退避。
- **客户端身份：** 同机回环反代默认信任，`WEBSPEAK_TRUST_PROXY=0` 显式关闭，`WEBSPEAK_TRUSTED_PROXIES` 声明其它反代；`fixed` 模式不向普通用户返回真实目标地址。

## 管理台与前端

- 事件流与日志按「什么事 / 严重吗 / 多久前」重构，时间智能分档；运营页分区页签化并支持 `?section=` 深链；审计事件下发 details 并记录登录来源 IP。
- 前端迁移到 React 19 + Vite，交互原语迁至 Radix/shadcn 原语面；产品 CSS 按组件族 `@layer` 化，浮层层级收敛到 `--ws-z-*` 阶梯变量。
- 聊天支持按页签删除本地记录、私聊会话未读角标与可见性门控；消息按身份左右分置。
- 新增受控 E2E 测试桥与 Playwright 冒烟门禁（375 / 768 / 1280 三视口），样式金样按部件锚点录制。

## 移出的能力

本版本删除了加速中继、Android 客户端、DemoView、访客计数与皮肤系统；管理端邀请功能一并移除——`fixed` 模式下站点链接本身即可免密进入，可撤销或过期的邀请链接无法构成真正的门禁。数据库 schema 升至 v12。

## 发布包与架构

- Windows：`windows-x64.zip`。
- Linux：`linux-x64.tar.gz`、`linux-arm64.tar.gz`。
- Docker：`ghcr.io/wslinnn/webspeak:0.3.0` 与 `latest`，同一镜像提供 `linux/amd64` 和 `linux/arm64`。
- `SHA256SUMS.txt` 提供 Release 附件的 SHA-256 校验值。

Windows ARM64 未纳入本次发布：`@discordjs/opus` 原生依赖不支持该构建目标。

## 验证

GitHub Actions 通过自动化测试、类型检查、前后端构建、Playwright 冒烟与 Docker 启动健康检查；Windows 与 Linux 发布包在独立目录执行内置健康检查（`/api/health` 的 `status` 与 `version`）。自动化构建通过不代表已完成真实 TeamSpeak 服务器互通验收。
